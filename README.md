# 💊 Pharmacy Management System
### Software Requirements Specification (SRS) Project

A comprehensive Software Requirements Engineering project that analyzes, designs, and documents a Pharmacy Management System aimed at digitizing pharmacy operations and improving efficiency in inventory management, billing, supplier tracking, and reporting.

---

## 📌 Project Overview

The Pharmacy Management System is designed to replace traditional manual pharmacy processes with a modern digital solution. The system helps pharmacy owners and staff manage medicines, generate invoices, monitor stock levels, track supplier records, and receive expiry alerts.

This project focuses on the complete Software Requirements Engineering lifecycle, including requirement gathering, stakeholder analysis, feasibility study, UML modeling, system design, and user interface prototyping.

---

## 🎯 Objectives

- Digitize pharmacy operations
- Improve inventory management
- Automate billing and invoice generation
- Manage supplier information
- Track medicine expiry dates
- Generate sales and inventory reports
- Reduce manual errors
- Improve operational efficiency
